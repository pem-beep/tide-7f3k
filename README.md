# Alles Liebe zur Hochzeit!

Öffne `docs/index.html` im Browser. Die Hochzeitskarte besteht aus HTML, CSS und JavaScript. Für statisches Hosting ist `docs/` der Veröffentlichungsordner. Ein Build-Schritt ist nicht nötig.

In `docs/gift.js` kannst du die Namen des Paars, die Nachricht und den Geschenktitel eintragen. Der Gutschein selbst kommt separat per E-Mail.

## GitHub Pages

Im GitHub-Repository unter **Settings > Pages** als Quelle **Deploy from a branch** und danach **main /docs** auswählen.

## Bildmaterial und Schrift

ImageGen hat die Lilienillustration, die Wellenornamente und die Lichtreflexe im Hintergrund erstellt. Das Foto auf der Rückseite zeigt das Scarlet Hotel und wurde für die Website bereitgestellt. Die Lizenz für DejaVu Sans Mono liegt in `docs/assets/dejavu-font-license.txt`.

Der Licht- und Kippeffekt ist inspiriert von [Pokémon Cards CSS](https://github.com/simeydotme/pokemon-cards-css) und [Hover Tilt](https://github.com/simeydotme/hover-tilt).
